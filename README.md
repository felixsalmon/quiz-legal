# Quiz Game Show

Projeto pessoal que eu montei pra jogar com meus amigos numa pegada nostálgica de Nintendo Wii.

**Detalhe importante:** Esse repositório não é um modelo base ou template limpo. Essa já é a minha versão final toda alterada. Deixei o repositório público pra galera poder acessar e ver como ficou o resultado final depois de jogarmos!
